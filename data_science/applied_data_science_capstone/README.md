# IBM Applied Data Science Capstone: SpaceX

## Project Overview

This project analyzes SpaceX Falcon 9 launch data to identify factors associated with first-stage landing success and explore the potential to predict launch outcomes.

## Project Workflow

1. **Data Collection:** Retrieve SpaceX launch data through API calls.
2. **Web Scraping:** Collect additional launch information.
3. **Data Wrangling:** Clean and prepare the datasets.
4. **Exploratory Data Analysis (EDA):** Analyze launch data using SQL and data visualization.
5. **Interactive Visual Analytics:** Explore launch sites and outcomes using Folium and Dash.
6. **Predictive Analysis:** Train and evaluate machine learning classification models.

## Repository Structure

- [`csv/`](csv/): Datasets used throughout the project.
- [`final_ipynb/`](final_ipynb/): Final notebooks and supporting code.

## Main Deliverables

- Data collection and web scraping notebooks.
- Data wrangling and exploratory analysis notebooks.
- Folium launch site mapping.
- Dash interactive dashboard and supporting answers.
- Machine learning prediction notebook.

## Purpose

This educational capstone demonstrates a complete data science workflow, from data collection and preparation to visualization and predictive modeling.
